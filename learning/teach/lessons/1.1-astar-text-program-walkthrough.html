每按一次“下一轮”，页面就模拟 astar_learning.py 的一次 while 循环：标出取出的格子、检查邻居、更新候选位置，并展示 g、h、f 和地图变化。

先知道整个程序在做什么

  1. 把地图、起点和终点放进变量。
  2. A* 重复取出当前 f 最小的位置，检查上下左右，更新更短的到达方式。
  3. 取出终点后，沿着前驱记录回到起点，得到路径。
  4. 把原始地图和带路径的地图打印出来。

页面按 Python 程序的同一套规则重放搜索状态，方便单步观察；代码框会指出当前对应的 Python 片段。
