# 学习偏好与进度备注

## 学习偏好

- 使用中文讲解，按步骤推进，但单次可以覆盖更多关联内容，不必把每个细小概念拆成一节。
- 先建立理解，再逐渐接触项目代码；避免一次给出规模很大的程序。
- 用户本次明确要求使用 HTML；在能帮助理解时加入演示图或动画。
- 内容简洁实用，不必过度强调视觉设计。
- 写代码时优先做小型、纯文本的项目程序，再逐步加功能。
- 不主动安排测验或练习；用户想动手时再一起做。
