# SDITADC v0.1_preview

三机器人智能仓库预览版：在线取送任务、硬优先级精确匹配、CBS 无碰撞路径协调、Pygame 左图右任务栏。

## 启动

本机独立环境位于 `.venv/`，双击 `launch.bat` 即可打开窗口。也可以在本目录运行：

```powershell
.\.venv\Scripts\python.exe main.py
```

移到其他电脑时重新创建环境，不能复制虚拟环境直接使用：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Python 建议 3.12～3.14，唯一第三方依赖是 pygame-ce 2.5.8。系统需要支持中文的字体；Windows 自动使用微软雅黑或黑体。

## 操作

- 左侧显示 32×24 仓库、20 组货架、20 个静态随机障碍、20 个取货作业点、4 个配送点和6个停车位。
- 三台机器人从三个相邻停车位出发，每机一次携带一件货物。装货、卸货各2步。
- 默认9个普通任务，自动生成默认关闭；开启后每45个仿真时间步新增一个普通任务。
- 右侧按编号从小到大列出任务，滚轮滚动。取消任务立即从所有列表移除；取消记录保留在运行报告中。点击任务高亮取送位置，取货点的“取”字显示在数字标记上方，也可以筛选未完成/已结束任务。
- “自定义任务”选择取送点和1～5级；“新增随机任务”直接新增普通任务。
- “提升一级”修改等级；“设为紧急”直接升到5级。1～4级影响下一轮待分配顺序，5级触发即时紧急调度。
- 紧急任务可抢占普通任务的取货行程；原任务返回队列，保留等级、创建时间与编号。
- 已派出且仍在去取货的普通任务升级为紧急时，会重新比较可用机器人，可能换机；装货开始后保持货物归属。
- 装卸动作不可中断；载货机器人先完成交付。没有立即可用机器人时，为紧急任务预约预计最合适机器人，显示“等待接手”。同级紧急任务不互相抢占。
- 取消仅适用于待分配、已预约、前往取货的任务；装货一旦开始就作为原子动作完成，货物不会凭空消失。
- 空格暂停/继续，N单步，A新增随机任务，S保存，R重试规划，Esc关闭新增任务窗口。
- 暂停时可以修改任务和更新计划，位置及仿真时间不变。速度单位是每秒仿真时间步。
- 保存产生 `outputs/last_scenario.json`（输入事件回放）与 `outputs/last_run.json`（指标、任务、机器人及逐步轨迹）。加载优先读取上次保存，否则读取普通初始场景。
- 回放按原事件时间新增任务及升级。最后一个记录事件之后不再生成未记录的自动任务；新的手动操作会终止余下回放，转为交互运行。
- 重置恢复当前命令行种子对应的普通初始场景并暂停。退出窗口时自动保存。

## 分配“最优”的准确范围

每轮按照5级、4级、3级、2级、1级顺序最大化分配数量，再最小化预计完成时间总和。用机器人占用位掩码动态规划精确求解匹配，不是最近机器人贪心；适用于固定三机器人，也能处理较长任务列表。

代价为：**机器人剩余必要动作时间 + 到取货点的网格最短路 + 装货 + 取送最短路 + 卸货**。紧急任务候选还包括完成当前不可抢占任务后释放的机器人。距离由实际障碍地图上的 BFS 得到，不是直线距离。

该保证针对本轮候选集合和给定代价矩阵。代价不预测未来插单、CBS 增加的等待和拥堵，因此不宣称整个运行过程的全局最优或实际完成时间全局最优。普通任务一旦派出保持归属，除非紧急抢占或取消。

## 路径与安全

- 时空 A* 状态包括位置、相对时间、剩余作业阶段及原子装卸时间；允许四邻域移动和WAIT。
- CBS 检测同格占用和对向换边，分别为冲突双方添加约束。包括空闲机器人，不会让它们从地图消失。
- 路线覆盖当前完整任务、已预约紧急任务和独立停车位。多个机器人可共享作业点，装卸占用必须错开。
- 路径代价按“紧急交付时间和、全部交付时间和、停车到达时间和”依次比较。优先权始终服从安全约束。
- 低层距离下界使用地图最短路。CBS 的优化范围是固定任务归属、固定作业顺序和搜索时域；预算耗尽不提供最优证明。
- 单次规划默认2秒、260步时域。失败时扩展时域做一次重试，仍失败则暂停并解释；不把超时说成无解。连续无执行进展也触发重规划及安全暂停。
- 界面主线程只读快照；后台单个工作线程串行处理命令和规划。用户命令在离散安全边界生效，已提交的一步先完成。
- 平滑运动只是视觉插值，规划仍是点机器人离散网格模型，不包含真实车体尺寸、速度或加速度。

## 文件与阅读顺序

```text
main.py                 启动入口、界面事件、后台规划协调
config.py               参数和当前版本内的路径
models.py               任务、机器人、作业点与界面快照
warehouse.py            规则货架、静态障碍、可达性、最短距离
scheduler.py            精确任务匹配及预计完成时间代价
simulation.py           任务状态机、紧急抢占、执行和恢复
planning/astar.py       带装卸阶段的时空 A*
planning/cbs.py         CBS 冲突搜索与预算
planning/validation.py  路径与碰撞检查
ui/renderer.py          地图、路线和机器人渲染
ui/task_panel.py        任务列表、状态和操作
ui/widgets.py           中文字体、基础绘制
persistence.py          输入回放与运行报告
scenarios/ordinary.json 唯一预设：普通搬运任务
tests/test_core.py      分配最优性、完整执行和安全规则验证
tests/test_ui.py        离屏模拟实际按钮、任务弹窗和暂停单步操作
outputs/                运行记录、指标、界面截图
```

推荐阅读 `models → warehouse → scheduler → planning → simulation → ui → main`。没有特殊情况演示场景；测试中的边界检查只用于验证安全和已承诺功能。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --headless --ticks 600
.\.venv\Scripts\python.exe main.py --headless --ticks 1200 --auto
.\.venv\Scripts\python.exe main.py --seed 17
```

导出界面截图而不保留窗口：

```powershell
$env:SDL_VIDEODRIVER = 'dummy'
.\.venv\Scripts\python.exe main.py --screenshot outputs/preview.png
.\.venv\Scripts\python.exe main.py --screenshot outputs/running.png --screenshot-tick 35
```

参数在 `config.py` 中修改。预览版没有真实库存、重量、电池、多件装载、动态障碍、连续控制或中途状态恢复；保存的是可复现输入，不是恢复运行现场的存档。
